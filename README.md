# Azure Analytics Solutions

This repository contains modular components for building data and analytics solutions using Microsoft's cloud stack + Databricks. The goal is to provide reusable and scalable resources across Databricks, Azure Functions, Microsoft Fabric, and SQL platforms.

---

## Repository Structure

- **AzureDatabricks/**  
  Notebooks and scripts for data engineering and analytics workflows in Azure Databricks using PySpark, including integration with Delta Lake.

- **AzureFunctions/**  
  Serverless functions for automating data workflows, REST API data integrations, and connecting services like Azure Blob Storage.

- **Fabric/**  
  Artifacts and definitions related to Microsoft Fabric, including REST API data integrations, pipelines, and LLM project with OpenAI.

- **SQL/**  
  SQL scripts for provisioning and querying Azure SQL Databases, including table creation, transformations, and stored procedures.

- **utils/**  
  Utility functions, shared Python modules, and helper scripts used across multiple components of the project.
